WhatsApp 준비 순서

  1. Meta for Developers 에서 앱을 만들고 WhatsApp 제품을 추가한다. 개발 중엔 제공되는 테스트 번호와 수신자(최대 5명)를 쓴다.
  2. 시스템 사용자 영구 토큰 → WHATSAPP_ACCESS_TOKEN, 전화번호 ID → WHATSAPP_PHONE_NUMBER_ID, 수신 번호(E.164, 쉼표) → WHATSAPP_TO.
  3. 먼저 WHATSAPP_TEMPLATE=hello_world, WHATSAPP_TEMPLATE_LANG=en_US 로 위 테스트 발송이 도착하는지 확인한다.
  4. 템플릿 trade_alert(Utility, 한국어)를 만들어 승인받는다. 본문: {{ '{{1}}' }} | {{ '{{2}}' }} 다음 줄 {{ '{{3}}' }}. 파라미터 값에 줄바꿈이 올 수 없어 본문 줄은 ' · ' 로 이어 보낸다.
  5. 승인되면 WHATSAPP_TEMPLATE=trade_alert, WHATSAPP_TEMPLATE_LANG=ko 로 바꾸고 엔진·백오피스를 재시작한다.
